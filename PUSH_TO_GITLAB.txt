WEAVE REPOSITORY HANDOFF
========================

The active repository is:
  https://github.com/regnant-io/weave.git

Before pushing:
  1. Review AUDIT.md and ROADMAP.md.
  2. Run the release checks documented in AUDIT.md.
  3. Revoke the ngrok credential that appeared in old commits and coordinate a
     Git-history rewrite. Removing it from the current tree does not revoke it.
  4. Review `git status` and commit only intended changes.

Push the current branch with:
  git push -u origin HEAD

If a GitLab mirror is still required, follow GITLAB_SETUP.md. Keep credentials
out of remote URLs, shell history, documentation, and deployment scripts.

For deployment, follow DEPLOY.md. The Kamatera helper reads NGROK_AUTHTOKEN from
the environment and defaults to the active GitHub repository. Override the clone
source with WEAVE_REPOSITORY_URL only when deploying an intentional mirror.
